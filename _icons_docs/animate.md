`rm-icon-spin`, `-spin-reverse`, `-pulse`, `-beat`, `-fade`, `-beat-fade`,
`-bounce`, `-shake`. Override speed with the `--rm-icon-duration` custom
property. Disabled automatically under `prefers-reduced-motion`.

<div class="example"></div>

```html
<span class="rm-icon rm-icon-spin rm-icon-gear"></span>
<span class="rm-icon rm-icon-pulse rm-icon-gear"></span>
<span class="rm-icon rm-icon-beat rm-icon-heart"></span>
<span class="rm-icon rm-icon-fade rm-icon-envelope"></span>
<span class="rm-icon rm-icon-beat-fade rm-icon-heart"></span>
<span class="rm-icon rm-icon-bounce rm-icon-chevron-down"></span>
<span class="rm-icon rm-icon-shake rm-icon-gear"></span>
```
