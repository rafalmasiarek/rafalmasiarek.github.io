`icon-spin`, `-spin-reverse`, `-pulse`, `-beat`, `-fade`, `-beat-fade`,
`-bounce`, `-shake`. Override speed with the `--icon-duration` custom
property. Disabled automatically under `prefers-reduced-motion`.

<div class="example"></div>

```html
<span class="icon icon-spin icon-gear"></span>
<span class="icon icon-pulse icon-gear"></span>
<span class="icon icon-beat icon-heart"></span>
<span class="icon icon-fade icon-envelope"></span>
<span class="icon icon-beat-fade icon-heart"></span>
<span class="icon icon-bounce icon-chevron-down"></span>
<span class="icon icon-shake icon-gear"></span>
```
