scale `rm-icon-1x` through `-10x`.

```html
<span class="rm-icon rm-icon-sm rm-icon-star"></span>
<span class="rm-icon rm-icon-star"></span>
<span class="rm-icon rm-icon-lg rm-icon-star"></span>
<span class="rm-icon rm-icon-2x rm-icon-star"></span>
<span class="rm-icon rm-icon-3x rm-icon-star"></span>
```
