Fixed steps `icon-2xs`, `-xs`, `-sm`, `-lg`, `-xl`, `-2xl`, or relative
scale `icon-1x` through `-10x`.

<div class="example"></div>

```html
<span class="icon icon-sm icon-star"></span>
<span class="icon icon-star"></span>
<span class="icon icon-lg icon-star"></span>
<span class="icon icon-2x icon-star"></span>
<span class="icon icon-3x icon-star"></span>
```
